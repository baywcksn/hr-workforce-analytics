# HR Workforce Analytics

An HR analytics portfolio project focused on analyzing employee demographics, workforce distribution, job satisfaction, compensation, and employee attrition.

## Project Objectives

- Analyze employee demographics and workforce composition.
- Understand employee attrition patterns.
- Explore relationships between job satisfaction, overtime, compensation, and attrition.
- Develop an interactive HR analytics dashboard.
- Provide data-driven insights to support HR decision-making.

## Dataset

**IBM HR Analytics Employee Attrition & Performance**

- Source: Kaggle
- Records: 1,470 employees
- Features: 35 columns
- Format: CSV
